# Madreseyar Teacher Android — 3.6.0 Daily Workflow

اپ Native معلم مدرسه‌یار با Jetpack Compose و ارتباط مستقیم با API هاست. هیچ WebView در اپ وجود ندارد.

## امکانات شاخص
- داشبورد Teal Pro
- ورود/MFA مطابق هاست و قفل بیومتریک هنگام باز شدن اپ
- حضور و غیاب سریع با همه حاضر + غایب موجه/غیرموجه
- استودیو حرفه‌ای آزمون مستمر و پایانی
- **دانش‌آموزان من با عکس و پرونده کامل**
- **دفتر نمره حرفه‌ای مستمر/پایانی**
- **دفتر کلاسی**
- **مرکز تکالیف و تصحیح**
- **تصحیح سؤال‌به‌سؤال آزمون**
- پیام، برنامه هفتگی، کتابخانه، بانک تمرین و سایر ابزارهای معلم

## هاست
برای امکانات جدید این نسخه، `host-patch/server.mjs` را طبق `host-patch/INSTALL-FA.md` روی هاست نصب کنید.

## Build
Workflow آماده در `.github/workflows/build-apk.yml` با Gradle 8.9 و Android 35 APK Debug می‌سازد.
